Native : the browser owns the focus trap, Escape, and the top layer. {% endcomment %} {% comment %} TWO RULES THAT BELONG TO THIS COMPONENT AND HAVE NOWHERE ELSE TO LIVE. The drawer's own styles sit in static/css/coverage.css for a stated reason: the drawer is drawn by the feed, the firm page AND My Applications, and a component defined in one page's inline styles is a component the other two silently lose (that is the bug that left My Applications with chips and no way to read the posting behind them). This partial is the one file all three pages include, so it is the only place other than that stylesheet where a rule reaches all three. The two below are here rather than in `directory/_styles.html` for exactly that reason — My Applications does not include `_styles.html`, so putting `.meta-read` there would have squared the button on two pages out of three and left the third a pill. {% endcomment %}
