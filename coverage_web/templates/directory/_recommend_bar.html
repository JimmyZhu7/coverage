{% load textstyle %} {% comment %} The "Picked for you" bar. Three states, and the difference between them is the whole point of the component: 1. No profile (signed out, or signed in with an empty survey) — one honest line and a way to fix it. Never cards. A bar labelled "picked for you" shown to someone we know nothing about is a lie that costs exactly the trust this page exists to earn. 2. A profile, but nothing clears the score threshold — say so plainly. The bar is allowed to be empty; padding it with the least-bad six would make a full bar meaningless on the days it is genuinely full. 3. Picks — up to six cards, each carrying the reasons that put it there. Every card's "why" chips come straight from the scorer (directory/recommend.py) and each chip's title attribute holds the long-form justification, including an explicit admission when a class-year match was inferred from a programme year rather than stated by the posting. Layout note: the cards are `min-height`, never a fixed height, and nothing here sets `overflow: hidden`. Two previous card bugs on this page were content clipped by a box smaller than its contents (a 97px chip in a 77px slot; 116px of content in a 90px box), so this component is built so that class of bug is not expressible — a card that needs more room grows, and the flex row keeps the whole set the same height as the tallest. {% endcomment %}
