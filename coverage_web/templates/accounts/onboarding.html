Per-step htmx wiring, and why it is per-step: * `change`, never `keyup` — so the school autocomplete's keystrokes (which fire their own `keyup` htmx request for the datalist) never drag a feed query along with them. {% comment %} THE ONE NUMBER ON THIS SITE THAT IS ALLOWED TO MOVE. Coverage removed its count-up animations on purpose (see base.html's note on `.dash-num`): a number that counts up on load is decoration, and on a throttled tab it froze mid-count and presented 235 as the real value of 908. This is the opposite case. The preview figure changes BECAUSE the student just ticked a chip, and the tween is the only thing that shows the cause and the effect are connected. Today it snaps from 2723 to 152 with no sign that the click did it. Three guards, all of them lessons from that removal: * it only ever runs between two values the server has already sent, never from zero on load, so there is no invented intermediate state; * `prefers-reduced-motion` and a hidden tab skip the tween entirely and take the final value immediately; * a `setTimeout` backstop writes the server's exact text at 260ms whatever happens to the frame loop, so a throttled tab cannot leave a wrong number on screen. That failure is the whole reason count-up was deleted, and it is closed here by construction rather than by hoping. `.ob-pv-num` is already `font-variant-numeric: tabular-nums` (_welcome_head.html), so the digits do not reflow while they run. {% endcomment %} {% script %} (function () { var box = document.getElementById("ob-preview"); if (!box) return; var DURATION = 200; var reduce = window.matchMedia("(prefers-reduced-motion: reduce)"); var before = null; function figures() { return Array.prototype.slice.call(box.querySelectorAll(".ob-pv-num")); } function readAll(els) { return els.map(function (el) { return parseInt(el.textContent.replace(/[^0-9-]/g, ""), 10); }); } box.addEventListener("htmx:beforeSwap", function () { before = readAll(figures()); }); box.addEventListener("htmx:afterSwap", function () { var els = figures(); var from = before; before = null; if (!from || from.length !== els.length) return; // The server's own text, kept verbatim: it is what lands at the end and // what a skipped tween shows immediately.
